# Décisions

Une décision d'architecture par fichier, numérotée : `0001-<sujet>.md`.

Chaque ADR donne sa date et son statut, puis :
- **Contexte** : ce qui oblige à décider, avec les faits ;
- **Décision** : ce qui est retenu ;
- **Écartés** : les options rejetées, et pourquoi ;
- **Conséquences** : ce qui change ensuite.

Une ADR ne se réécrit pas : une décision nouvelle la remplace, et l'ancienne renvoie à la nouvelle.
