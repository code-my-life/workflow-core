# ADR 0015 : les ADR remplacées ou amendées

Date : 2026-11-11. Statut : accepté. Reprise de la décision AD-15 de l'architecture du chantier archi-studio
(2026-11-11), qui la donne pour adoptée.

## Contexte

Ce que la décision empêche : une règle de dépôt contournée sans ADR.

## Décision

chacune est remplacée ou amendée par une ADR écrite avant le changement qu'elle autorise. `workflow-core` naît avec une ADR par AD de ce document.
